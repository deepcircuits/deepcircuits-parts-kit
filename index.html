Electronic parts, drawn by code.

Original SVG artwork for boards, chips, sensors, displays and modules. Every part is at true size on the 0.1-inch grid, returns its pin positions, and shows its state: LEDs light, screens show text, servos turn.

npm install github:deepcircuits/deepcircuits-parts-kit
DocumentationBrand bookMIT licence
import { drawPart } from '@deepcircuits/parts-kit';

// Any part by its catalog id, with its options.
const lcd = drawPart('character-lcd-16x2', {
  lines: ['Hello, world', 'DeepCircuits'],
});
el.innerHTML = lcd.svg;  // the drawing
lcd.pins;                // [{ name, x, y }, …]
