# PulseSensor

The pulse (heartbeat) sensor as photographed: a round `pcb-black` board 16 mm across with the white heart printed on it, the green LED at the heart's top and the light sensor below it, a tiny hole each side, three legs to the pins below (`GND`, `VCC`, `OUT`). Provide `on` for the LED.

- The LED is `data-hook="pulse-led"` (an indicator with `data-on-fill` and `data-off-fill`); the editor lights it while the sensor is powered.
- The legs end on the grid a pitch apart, so the sensor plugs into a breadboard like its cable's header does.
