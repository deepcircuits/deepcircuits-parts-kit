# Symbols

The schematic symbols beside LogicSymbol, in `currentColor` so they follow the canvas: the 2-input multiplexer (`A` is input 0, `B` input 1, `SEL` below, `OUT` right), the D flip-flop box with its clock wedge and Q-bar (`set` adds `S` above, `reset` adds `R` below), the clock generator with its square wave (`CLK` right, `GND` below), the function generator with the `wave` it makes (sine, triangle or square; `OUT` right, `GND` below), the supply bar captioned with its `voltage`, and the note glyph the library shows for a canvas text note.

- Every output lead carries `data-level-pin` with its pin index, as LogicSymbol's do; the canvas colours it by the solved level.
- Every pin is on the grid from the first; the clock's pins move from the catalog's fractional places to whole pitches.
