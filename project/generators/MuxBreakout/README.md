# MuxBreakout

`muxBreakout`: the CD74HC4067 16-channel analog multiplexer breakout, 48 × 18 mm on a `pcb-purple` board. The channel pins `C0` … `C15` run along the top edge; the `SIG`, `S3`, `S2`, `S1`, `S0`, `EN`, `VCC`, `GND` header runs along the bottom edge, six pitches below and centred under them, so the board straddles a breadboard's centre channel. The chip sits between the rows in SOIC-24 with its decoupling capacitor, and a mounting hole is at each end.

- Pins are `SIG` … `GND`, then `C0` … `C15`.
- `finish`: the board colour, purple by default.
